# Light-Trader Sample Strategy

Public sample strategies that show how [Light-Trader](https://github.com/networknt/light-trader) works: how a
strategy is written as a WebAssembly component, replayed over history, and eventually run in an accepted
trade-server on a separately authorized IB paper account. The [overview](samples/overview.md) tracks current delivery status, and the
[quick start](samples/quick-start.md) builds and replays the canonical upstream ORB.
See the [architecture](samples/architecture.md) and [milestones](samples/implementation.md).

The samples are examples for learning and for testing the engine, not trading advice. See
[Sample strategies](samples/overview.md) to start.

See [Contributing to the documentation](contributing.md) for instructions on
building the book and adding pages.
